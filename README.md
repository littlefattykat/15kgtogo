# 15kgtogo Version 3.1 Fitness, mobile-fit revision

This complete static GitHub Pages package preserves the uploaded app and applies only these requested changes:

- The iPhone portrait date field is constrained to the card width.
- Previous, Today, and Next are equal-height 58 px controls in a fixed mobile grid.
- The word `used` is removed from macro cards.
- Fitness rings have smaller gaps.
- All text is removed from the center of the rings.

## Deploy

Upload all contents to the repository root. Keep `.github/workflows/pages.yml`. In GitHub, select **Settings > Pages > GitHub Actions**. Export existing app data before clearing Safari storage.
